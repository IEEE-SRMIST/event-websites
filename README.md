# IEEE SRMIST event websites

The original code of past IEEE SRMIST event websites, kept in one place for reference. Nothing here is built or deployed.

| Folder            | Event                   |
| ----------------- | ----------------------- |
| `concepto-2021`   | Concepto 2021           |
| `concepto-2024`   | Concepto 2024           |
| `hacktrix-2022`   | HackTrix 2022           |
| `hacktrix-2024`   | HackTrix 2024           |
| `evolve`          | EVOLVE 2024             |
| `hyperforge`      | Hyperforge 2023         |
| `technozest`      | TechnoZest 2023         |
| `hello-cloud`     | HELLO CLOUD! 2023       |
| `events-platform` | Events platform, 2023   |

- Each folder holds that repo's `main` branch with its full commit history.
- Every other branch and every pull request is kept as a tag: `archive/<repo>/<branch>` and `archive/<repo>/pr-<number>`.
- Each merged repo's issues and pull requests are saved in its folder's `issues-and-pull-requests.md`.
